iPhone 免电脑安装

安装全能签

全能签是观序苹果版的专用签名工具。装上之后，填入你的 Apple ID，它会自动拉取观序安装包，在手机本地完成签名并安装到本机——全程不需要电脑，也不需要越狱。

一键安装全能签
  1. 请用 iPhone 自带的 Safari 打开本页，点上方按钮；
  2. 弹出安装确认框时点「安装」，图标会自动出现在桌面；
  3. 首次打开若提示「未受信任的企业级开发者」，到「设置 → 通用 → VPN与设备管理」中选择信任后即可打开。
按钮点了没反应？说明当前还没有生成签名版本（签名服务需要有效的开发者证书与描述文件）。 此时请用下方备用方式：下载未签名包，自行用 AltStore / Sideloadly 侧载一次；之后全能签即可自行续签。
备用：下载未签名 IPA

装好之后怎么用

  1. 打开全能签，填入你的 Apple ID 账号与密码（仅在本机使用，不会上传）；
  2. 点「开始安装」，它自动完成签名并把观序装到本机；
  3. 签名完成后全能签会自动关闭并进入休眠，只能用同一账号重新签名续期。
